Video_Factory

A personal tool for uploading my own videos to my YouTube channels and viewing their statistics.

What the app does

Video_Factory is a private desktop/web application used by its owner to manage his own YouTube channels. It runs locally on the owner's computer and is not offered to the public.

  • Uploads finished videos, titles, descriptions, tags and thumbnails to the owner's YouTube channels.
  • Schedules video publication time.
  • Shows channel statistics: subscribers, views and number of videos per day, week and month.

Why the app requests access to your Google account

The app uses Google OAuth 2.0 to sign in to the owner's Google account and calls the YouTube Data API and YouTube Analytics API only for the following purposes:

  • youtube.upload — to upload videos to the signed-in user's channel;
  • youtube / youtube.force-ssl — to set video metadata, thumbnails and publish time;
  • youtube.readonly and yt-analytics.readonly — to show channel and video statistics inside the app.

Data is used only to provide these features to the user who signed in. It is not sold, shared with third parties or used for advertising. Details are in the Privacy Policy.

Video_Factory's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

Video_Factory uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using Video_Factory you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy. You can revoke Video_Factory's access to your data at any time on the Google security settings page.
